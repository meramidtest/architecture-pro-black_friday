# ADR: Операции которые могут использовать реплики для чтения данных

## Контекст

#### Операции чтения с коллекцией "orders"

- Поиск истории заказов конкретного пользователя.
- Отображение статуса заказа.


#### Операции чтения с коллекцией "products"

- Поиск товаров по категориям и фильтрация по диапазону цен.
- Описание товара на странице продукта.

#### Операции чтения с коллекцией "carts

- Получение текущей корзины по фильтру { session_id, status:"active" } или { user_id, status:"active" }.

## Решение

Операции чтения

| Операция                                                               | БД target (primary/secondary) | Допустимая задержка репликации | Обоснование
|------------------------------------------------------------------------|-------------------------------|--------------------------------| ---
| Поиск истории заказов конкретного пользователя                         | secondary                     | <100 ms                        | Задержка в просмотре истории заказов клиента не критична. Можно читать с реплики с неболшой задержкой
| Отображение статуса заказа                                             | secondary                     | <500ms                         | Задержка в просмотре статуса заказа клиента не критична. Можно читать с реплики с повышенной задержкой
| Поиск товаров по категориям и фильтрация по диапазону цен              | secondary                     | <500ms                        | Задержка с момента добавления нового товара, до появление в поиске не критична. Можно читать с реплики с повышенной задержкой
| Описание товара на странице продукта                                   | secondary                     | <500ms                        | Задержка с момента редактирования товара, до отображения этих данных на страницах у пользователей не критична. Можно читать с реплики с повышенной задержкой
| Получение текущей корзины по фильтру                                   | primary                       | -                              | Задержки в получении текущей корзины недопустимы, так как это может привести к потере записей в корзине, или создания заказа с неактуальными продуктами
