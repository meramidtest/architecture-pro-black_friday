# pymongo-api

## Как запустить

Запускаем mongodb и приложение

```shell
docker compose up -d
```

Заполняем mongodb данными

```shell
./scripts/mongo-init.sh
```

## Как проверить

Откройте в браузере http://localhost:8080

## Доступные эндпоинты

Список доступных эндпоинтов, swagger http://<ip виртуальной машины>:8080/docs

## Посмотреть общее колоичество документов в БД

1. Открыть http://localhost:8080
2. Поле `mongo_total_documents` отображает общее количество документов в БД


## Посмотреть колоичество документов в каждом из шардов

1. Открыть http://localhost:8080
2. Поле `documents_per_shard` отображает общее количество документов по шардам и репликам
